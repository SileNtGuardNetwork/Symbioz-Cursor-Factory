# Support

Symbioz Cursor Factory is currently in founder-led early alpha.

## Where to ask for help

- use GitHub Issues for reproducible bugs and feature requests
- use the provided templates and include environment details
- do not publish secrets, access tokens, customer data, private repository contents, or raw MCP credentials

## What support currently covers

- repository setup questions
- Rule and Skill discovery problems
- validator failures
- documentation gaps
- MCP profile design and permission questions
- reproducible installation issues

## What support does not currently cover

- emergency production incidents
- recovery of lost credentials or data
- legal, compliance, or security certification
- custom implementation work inside private products
- guarantees for third-party MCP servers or external services

## Security issues

Do not open a public issue for a vulnerability that could expose credentials, private data, or destructive access. Follow [SECURITY.md](SECURITY.md).

## Response expectations

This is an early open-source project without an SLA. Reports with clear reproduction steps, evidence, and bounded scope receive priority.
