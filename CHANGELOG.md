# Changelog

All notable changes to Symbioz Cursor Factory will be documented in this file.

The project follows semantic versioning once the public release line begins.

## [Unreleased]

### Added

- repository foundation and public product definition
- English and Russian README files
- universal Cursor Rules for architecture, implementation, review, QA, design, security, and documentation
- initial Agent Skills for product brief, architecture, controlled implementation, browser QA, code review, security review, documentation sync, and release preparation
- Cursor settings guide
- MCP profiles and MCP catalog
- installation, troubleshooting, FAQ, release checklist, and example project contract
- GitHub Actions validation workflow
- repository validator for required files, Skill contracts, Rule frontmatter, local links, workflow permissions, and secret patterns
- issue templates, pull request template, CODEOWNERS, and support files

### Current limitations

- Rules and Skills are not yet operationally verified in a clean local Cursor installation
- OAuth-based MCP integrations are not yet verified
- no installer or environment doctor exists yet
- no public alpha release has been tagged
